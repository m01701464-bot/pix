# Пикс — ИИ-помощник поверх экрана (Android)

Пиксельный помощник-глаз, который всегда висит поверх экрана:
- **Отвечает сам, если ты молчишь 2 минуты** — по сути вопроса, с учётом переписки. Если за это время ты открыл чат или ответил — не вмешивается.
- **«Я занят»** — сам отвечает на входящие в Telegram, WhatsApp, ВК, MAX, Viber, SMS и др. (через кнопку «Ответить» в уведомлении), помечает автоответ меткой 🤖, не спамит (не чаще раза в N минут на чат), пропускает рекламу/коды/«ок».
- **Пишет как ты, помнит людей, фильтр контактов, вечерняя сводка.** Глаз засыпает ночью, кружится от тряски и смотрит за пальцем.
- **Будит при «срочно»** — если пишут «срочно», присылает громкое уведомление.
- **Поручения** — тап по Пиксу → чат: «напомни в 15:30 забрать посылку», «добавь задачу», «что мне писали?», «ответь Саше, что буду в 7», «я занят на 2 часа».
- Пикс анимирован: моргает, покачивается, радужка меняет цвет (бирюзовая — свободен, зелёная — дежурит, синяя — думает и бегает глазами, красная — тревога), на значке — число пропущенных сообщений.

Мозги — Google Gemini (бесплатный ключ без карты: aistudio.google.com → Get API key) или Claude API (платно). Ключ хранится только на телефоне.

## Как получить APK

### Вариант 1 — GitHub (без компьютера с Android Studio)
1. Создай репозиторий на github.com и загрузи в него **всё содержимое** этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → workflow **Build APK** запустится сам (или нажми *Run workflow*).
3. Через ~5 минут открой завершённый запуск → внизу **Artifacts → Pix-apk** → скачай zip, внутри `app-debug.apk`.

### Вариант 2 — Android Studio
Open → выбери папку `Pix` → дождись синхронизации → **Build → Build APK(s)**.
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск
1. Установи APK (разреши установку из неизвестных источников).
2. **Android 13+:** Настройки → Приложения → Пикс → ⋮ → «Разрешить ограниченные настройки» — без этого система не даст доступ к уведомлениям.
3. В приложении нажми все «Разрешить» в блоке «Доступы».
4. Вставь API-ключ, нажми «Проверить ключ».
5. Напиши, как тебя зовут и как отвечать за тебя → «Сохранить».
6. «Показать Пикса на экране».

## Ограничения
- Ответить можно только в чат, чьё уведомление ещё висит и в нём есть кнопка «Ответить» (так устроен Android).
- Пикс не звонит, не покупает и не нажимает кнопки внутри других приложений.
- Каждый ответ тратит запрос к Claude API (автоответы идут на быстрой дешёвой модели).
